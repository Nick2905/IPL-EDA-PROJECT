# IPL 2022 Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis on IPL 2022 data to understand
team performance, match outcomes, and key trends.

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis
- Match-wise and team-wise performance
- Venue analysis
- Winning trends
- Data visualization using charts and graphs

## 📁 Dataset
- IPL.csv (public dataset)

## 📈 Visualizations
All visualizations are created using Matplotlib and Seaborn inside the notebook.

## ✅ Conclusion
This project helped in understanding real-world data analysis workflow using Python.
